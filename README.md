# 속닥 — 오프라인 부스 버전

`demo` (`d5e2294`)에서 분기한 `codex/offline-booth`입니다.

## 실행

1. `ToDoc.xcodeproj`를 Xcode에서 열고 `ToDoc` 스킴을 선택합니다.
2. 실제 iPhone에 설치할 때 Signing의 개발 팀을 확인하고 실행합니다. 기존 프로젝트와 동일하게 iOS 27 이상이 필요합니다.
3. 로그인 없이 홈으로 들어갑니다. Supabase·카카오·Amplitude 키, `Secrets.xcconfig`, 외부 Swift 패키지가 필요하지 않습니다.
4. 부스 전 실제 사용할 iPhone에서 비행기 모드를 켜고 Wi-Fi도 끈 상태로 아래 시나리오를 한 번 확인합니다.

## 오프라인 동작

- **진료 전 기록:** 이전 통증·증상이 없어도 오늘을 선택해 메모와 기분을 저장합니다. 같은 날 여러 번 체험할 수 있습니다. 작성 중 초안도 앱 재실행 후 복원됩니다.
- **통증 기록:** 부위·복용 전 점수 저장, 타이머 복원, 복용 후 점수 저장, 기록 조회가 모두 기기에서 수행됩니다.
- **증상 대화:** 앱에 포함된 질문·키워드 규칙으로 바로 문자 대화를 시작합니다. 선택 버튼이나 자유 입력으로 답하고 요약을 확인·수정한 뒤 저장합니다. Apple Intelligence나 모델 다운로드에 의존하지 않습니다. 판단이 어려운 답은 원문과 ‘모름’으로 보존합니다. 질문하지 않은 항목을 가짜 답변으로 채우지 않습니다.
- **음성:** 이미 설치된 한국어 음성 인식 자료만 사용합니다. 자료가 없거나 마이크를 허용하지 않아도 문자 대화로 이어갈 수 있습니다. 앱에서 음성 자료를 다운로드하지 않습니다.
- **기록 보존:** 중단된 대화도 기기에 남기고 다음 실행 시 기록으로 복구합니다. 같은 대화를 중복 복구하지 않도록 저장 파일에 처리 내역을 함께 기록합니다.
- **기타:** 프로필 수정, 알림 시간 저장, 기기 알림, 로컬 Live Activity를 지원합니다. 로그인·병원 연결·웹 고객지원·원격 푸시·분석 이벤트 전송은 사용하지 않습니다.

## 부스 반복 체험

설정 → 관리자 설정의 기존 코드 **1120**으로 들어갑니다.

- `통증 1시간 스킵`: 기다리는 기록을 30초 뒤 복용 후 기록 가능 상태로 바꿉니다. 시간 조정은 테스트용이며 실제 복용 기록과 혼동하지 않게 사용합니다.
- `증상 초기화`, `진료 전 기록 초기화`: 오늘 기록을 지우고 다시 체험합니다.
- `이 기기의 모든 기록 지우기`: 확인 후 전체 기록과 작성 중인 진료 전 초안을 지웁니다. 다음 참여자에게 기기를 넘기기 전에 사용할 수 있습니다.
- `라이브 액티비티 모두 닫기`: 쌓여 있는 통증·증상 실시간 현황을 닫습니다. 저장된 기록은 삭제하지 않습니다.
- 잠금화면 또는 길게 눌러 펼친 실시간 현황의 **×**로 해당 항목만 닫을 수 있습니다. 닫은 통증 타이머는 앱 재진입 시 자동으로 다시 표시하지 않습니다. 새 통증 기록은 새 타이머를 시작합니다.
- 알림 설정은 **00:00~23:59** 전체 시간대를 지원합니다.
- `목데이터 채우기`는 명시적으로 실행할 때만 예시 데이터를 추가합니다. 일반 대화는 실제 입력만 저장합니다.

## 저장 위치와 범위

앱의 `Library/Application Support/OfflineBooth`에 항목별 JSON 파일을 원자적으로 저장합니다. 기기 파일 보호를 적용하고 iCloud·기기 백업 대상에서 제외합니다. 중단 대화는 `PendingCareCalls`를 사용합니다. **앱을 삭제하면 기록도 삭제되며, 다른 기기나 서버로 동기화되지 않습니다.** 기존 서버 기록은 가져오지 않습니다.

## 검증

- iOS 27 시뮬레이터 Debug 빌드·실행 및 실기기용 Release 빌드(서명 제외) 성공.
- XCTest 78개 + Swift Testing 386개, 총 **464개 통과**.
- 새 저장소 인스턴스에서 세 종류 기록·프로필 복원, 날짜/환자 구분, 수정·삭제, 저장 파일 손상 오류, 통증 후속 기록 시점, 초안 복원, 대화 중단·중복 복구, 모델 없는 대화 완료를 검증했습니다.
- 시뮬레이터에서 진료 전 메모·기분, 통증 7점, 증상 7개 ‘없음’ 응답을 실제 화면으로 저장했습니다. 앱 종료·재실행 후 통증·증상 기록 표시와 진료 전 저장 파일을 확인했습니다. 관리자 대기 시간 단축, 복용 후 점수 저장, 체험자 설정 화면, 전체 기록 초기화도 확인했습니다.
- 실물 iPhone의 비행기 모드·마이크·한국어 음성 자료 상태는 행사에 사용할 기기에서 마지막으로 확인해야 합니다.

테스트 실행: `swift test --build-system native --disable-sandbox -j 4`. 이 환경의 Swift 기본 빌드 엔진이 멈춰 native 엔진으로 검증했습니다. 네트워크 저장 코드·외부 SDK 제거 검사는 `python3 tools/verify_offline.py`로 실행합니다.

## 라이브 액티비티 보완

테스트 항목에 기록 ID가 없어 기존 정리 대상에서 누락되고, 기존 항목을 종료하기 전에 새 항목을 요청해 개수 제한 오류가 발생하던 흐름을 수정했습니다. 종료 후 생성 순서를 보장하고 동시 요청을 직렬화합니다. 시작 실패는 통증 저장 실패와 구분해 안내하고 다시 표시할 수 있습니다. 관련 회귀 테스트 13개를 통과했습니다.
