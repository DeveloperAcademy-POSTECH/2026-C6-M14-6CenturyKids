# 서버 없는 온보딩·회원가입 Preview

`ToDoc/Features/Auth/Previews/AuthInteractivePreview.swift`를 열고 Canvas의 **온보딩 → 가입 완료 · 서버 없는 체험**을 Live로 실행합니다.

1. 시작하기 → 소개 4페이지의 다음 → 회원가입을 누릅니다. 소개는 건너뛰어도 됩니다.
2. 환자를 선택하고 이름·이메일·비밀번호·확인을 진행합니다. 예시 값이 기본으로 채워져 있으며 직접 수정할 수 있습니다.
3. 약관의 화살표로 예시 본문을 열어보고, 필수 약관에 동의한 뒤 다음으로 갑니다. 실제 약관이 아닌 화면 체험용 내용입니다.
4. 필수 기본 정보(이름·생년월일·성별) → 암종 → 병기를 입력합니다. 암종의 기타는 자유 텍스트가 필수이며 병기는 0~4기 또는 ‘모르겠어요’입니다.
5. 의사 코드 `PRE123`을 확인하거나 ‘지금은 건너뛰기’를 누릅니다.
6. 환자 정보·암종·병기를 확인하고 ‘확인하고 가입 마치기’를 누르면 가입 완료 화면으로 이동합니다.
7. 상단 ‘처음부터’는 가입 진행과 동의를 초기화합니다. ‘예시 입력’은 입력값만 다시 채우며 동의는 선택하지 않습니다.

기존 제품 View와 ViewModel을 사용하며 이 DEBUG Preview에만 메모리 저장소·예시 약관을 주입합니다. 실제 서버·메일·영구 저장소는 사용하지 않고 실제 계정도 만들지 않습니다. 제품 DI·인증 검증·기본 홈 진입은 그대로입니다. 완료 뒤 로그인 화면까지 이동할 수 있지만 로그인 성공과 비밀번호 복구는 이 체험 범위에 포함하지 않습니다.

암종 입력부터 확인하려면 같은 파일의 **암종 기타 · 자유 텍스트부터**, **병기 · 모르겠어요** Preview를 선택합니다. 기본 정보 → 암종·병기 → 선택 의사 코드의 순서는 선행 PR #107에 반영된 것을 사용합니다.
