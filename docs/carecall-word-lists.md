# 케어콜 낱말 목록 (`ToDoc/Resources/Config/side_effects.json`)

케어콜 엔진은 모델 결과를 환자 말로 한 번 더 고친다. 그때 쓰는 낱말 목록이 어디에 쓰이고 어떻게 맞추는지 정리한다.
모든 비교는 띄어쓰기·문장 부호를 빼고 한다 ("안 했어요" = "안했어요"). 같은 말을 띄어쓰기만 바꿔 두 번 넣지 않는다.

## 새 말투를 넣을 때

| 환자 말 | 넣을 곳 |
|---|---|
| 어느 항목에서나 "없다"는 끝말 ("…없심더", "평소랑 같아요") | `noSuffixes` |
| 답 전체가 짧은 "아니요"류 ("딱히요") | `shortAnswers.no` (답 전체가 같아야 맞음) |
| 그 항목을 물을 때만 정상이라는 끝말 ("변은 매일 봐요") | 그 항목의 `absentPhrases` |
| 그 항목을 물을 때 평소대로 한다는 답 ("한 그릇 비워요") | 그 항목의 `usualAnswer.endings` (줄었다는 말은 `unless`) |
| "없다"가 붙어도 증상이 있다는 말 ("입맛 없") | 그 항목의 `presentPhrases` (어느 질문에서나) |
| 그 항목을 물을 때만 증상이 있다는 말 ("안 나와요" = 변비) | 그 항목의 `answerPhrases` |
| 목록 밖 증상 표현 ("욱신", "떨려") | `symptomHints` |
| 정상이라는 낱말 ("멀쩡", "말짱") | `normalWords` |
| '그 밖에'를 끝맺는 말 ("그게 다예요") | `closingEndings` |
| 몸 부위 낱말 ("눈꺼풀") | `body_parts.json` |

## 전역 목록

| 목록 | 맞추는 방법 | 쓰는 곳 |
|---|---|---|
| `shortAnswers.yes` / `.no` | 군말(`fillers`)을 뺀 답 **전체**가 같을 때 | 모델 없이 처리하는 짧은 답 (네·아니요) |
| `shortAnswers.fillers` | 답 앞뒤의 군말을 뺄 때 | "음 아니요" → "아니요" |
| `noPrefixes` | 답 전체가 이 말과 같을 때 (분명한 '없음' 판단), 또는 이 말로 시작할 때 (이유 답 판단) | 유무 질문의 분명한 없음 |
| `noSuffixes` | 답이 이 말로 **끝날** 때 | 없다는 답 (`soundsNegative`), 분명한 없음 |
| `normalWords` | 이 말이 **들어 있을** 때 | 정상이라는 답: 유무 질문의 '없음', '그 밖에'에서 기록하지 않기, 애매한 답이 아님 |
| `closingEndings` | 답이 이 말로 끝나고 증상 표현·항목 낱말·몸 부위가 없을 때 | '그 밖에' 끝맺는 말 → 기록하지 않음 |
| `symptomHints` | 이 말이 들어 있고 바로 앞뒤가 부정이 아닐 때 ("안 아파요", "아픈 데는 없어요"는 아님) | 증상을 말한 답: 첫 답 되묻기, "언제부터", 기타 증상 원문 기록 |
| `openingConcerns` | `symptomHints`와 같은 방법 | 첫 질문의 컨디션이 나쁘다는 말 ("힘들어요") |
| `openingFine` | 들어 있을 때 | 첫 질문의 괜찮다는 답 |
| `unknownAnswers` / `vagueAnswers` | 들어 있을 때 (있다·없다·숫자·증상 낱말이 함께 있으면 아님) | 모르겠다·애매한 답 → '모름' + 원문 |
| `repeatRequests` | 답 전체가 이 말(과 공손한 말)뿐일 때 | 다시 말해 달라는 말 → 질문 반복 |
| `reasonSuffixes` | 답이 이 말로 끝날 때 | 이유 답 ("입이 아파서요") |
| `onsetWords` | 들어 있을 때 | 시작 시점을 이미 말함 → "언제부터"를 묻지 않음 |
| `followUpCall.*` | 들어 있을 때 | 같은 날 다시 거는 통화의 "그대로예요"·"나았어요" |

## 항목별 목록 (`effects[]`)

| 목록 | 맞추는 방법 | 쓰는 곳 |
|---|---|---|
| `keywords` | 들어 있을 때 (`said`), 바로 앞뒤가 부정이 아닐 때 (`affirmed`) | 그 항목을 말했는지: 항목 옮기기, 근거 확인, 다른 항목 '없음' 거르기 |
| `presentPhrases` | 두 낱말이 한 절에서 차례로(사이 8자 이내), 뒤가 부정이 아닐 때. 약 이야기 절은 아님 | 어느 질문에서나 '있음' (그 항목을 묻기 전이면 묻는 차례까지 미룸) |
| `answerPhrases` | `presentPhrases`와 같은 방법 | **그 항목을 물을 때만** '있음' |
| `absentPhrases` | 답이 이 말로 끝날 때 | 그 항목을 물을 때 '없음' |
| `usualAnswer` | 답이 `endings`로 끝나고 `unless`·"…만"·증상 표현·대조가 없을 때 | 그 항목을 물을 때 '없음' (모델이 '있음'이라 해도) |
| `keywordRequired` | — | 첫 답·'그 밖에'에서 이 항목 낱말 없이 고르면 기타 증상 (저림·피부) |

목록끼리 겹치는 말("괜찮아요"가 `noSuffixes`·`noPrefixes`·`shortAnswers.no`에 모두 있음)은 쓰는 곳과 맞추는 방법이 달라 일부러 둔다.
응급 키워드·위기 표현은 `emergency_rules.json`에 따로 있고 의료진 확인 전에는 바꾸지 않는다.
